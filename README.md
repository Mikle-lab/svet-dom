# Свет дома

Обновления Android-приложения «Свет дома» (мониторинг света, инвертора и АКБ).

- `version.json` — номер последней версии (приложение проверяет его само)
- `svet-dom-*.apk` — файлы приложения

Установка: скачать последний APK и открыть на телефоне. Дальше приложение обновляется само (раздел «Обновления»).
